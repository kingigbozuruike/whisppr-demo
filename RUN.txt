🚨 WHISPPR DEMO - HOW TO RUN EVERYTHING
===============================================================================

📋 PREREQUISITES
- Node.js 18+ installed
- iOS Simulator or Android Emulator
- Your phone number already configured in backend/.env ✅

===============================================================================
⚡ QUICK START (2 TERMINALS)
===============================================================================

TERMINAL 1 - Backend:
    cd backend
    npm start

TERMINAL 2 - Mobile App:
    cd mobile-app
    npx expo start
    # Press 'i' for iOS or 'a' for Android

Then press the SOS button in the app!

===============================================================================
⚙️  ONE-TIME SETUP (Only if not installed)
===============================================================================

1. Install Backend Dependencies:
   cd backend
   npm install

2. Install Mobile Dependencies:
   cd mobile-app
   npm install

3. Configure Mobile App (IMPORTANT!):
   - Edit mobile-app/App.js line 20
   - Find your IP: ipconfig getifaddr en0
   - Change: const BACKEND_URL = 'http://YOUR_IP:3000';

===============================================================================
🧪 HOW TO TEST
===============================================================================

Test Backend:
    cd backend
    npm test
    # Should send SMS to your phone!

Test with curl:
    curl http://localhost:3000/health
    
    curl -X POST http://localhost:3000/sos \
      -H "Content-Type: application/json" \
      -H "x-api-key: demo-secret-key" \
      -d '{"name":"Test","lat":32.52,"lng":-92.63,"platform":"test"}'

===============================================================================
🐛 TROUBLESHOOTING
===============================================================================

"Backend won't start":
    - Check if port 3000 is free: lsof -ti:3000
    - Kill process: kill -9 $(lsof -ti:3000)

"Mobile app can't connect":
    - Find IP: ipconfig getifaddr en0
    - Update mobile-app/App.js line 20
    - Ensure backend is running
    - Check both on same WiFi

"No SMS received":
    - Check backend console for "SMS sent successfully"
    - Verify backend/.env has DEMO_NUMBER_1=+17135848950
    - Check quota: curl https://textbelt.com/quota/YOUR_KEY

"Tests fail":
    - Make sure backend is running FIRST
    - Then run npm test in NEW terminal
